# Simple Interest Calculator

This repository contains a simple interest calculator script and project files.

## How It Works
Simple interest is calculated using:
`Simple Interest = (Principal * Rate * Time) / 100`

### Inputs
- **Principal:** Initial amount of money
- **Rate of Interest:** Annual interest rate (in percent)
- **Time Period:** Duration (in years)

## Usage
Run the script in a Bash terminal:
```bash
bash simple-interest.sh
